# Support

Use [GitHub Issues](https://github.com/safal207/telegram-for-codex/issues) for
non-sensitive installation and product bugs.

Before filing an issue:

1. Run `telegram-codex-doctor`.
2. Confirm you are using the latest tagged beta or current `main`.
3. Include the operating system, Python version, Codex version, install method,
   and the doctor check names that failed.
4. Replace usernames, chat IDs, paths, domains, and account identifiers with
   synthetic values.

Never include Telegram message text, phone numbers, API credentials, login
codes, 2FA passwords, session files/strings, OAuth tokens, bot tokens, or the
contents of `config.env`. Use the private process in [SECURITY.md](SECURITY.md)
for security-sensitive reports.
